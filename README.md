# Study-planner
Une application de gestion de tâches pour étudiants 
## Fonctionnalités
- Créer des tâches avec titre, échéance et priorité
- Marquer les tâches comme terminées 
- Filtrer les tâches par matière
- Définir des niveaux de priorité (basse / moyenne / haute)

## Stack technique
- Next.js (framework React)
- Déployé sur Vercel

### User Stories 
- " En tant qu'étudiant je veux modifier une tâche existante, afin d'adapter mon planning lorsqu'une consigne ou une chance change."
- " En tant qu'étudiant, je veux supprimer une tâche devenue inutile, afin de garder mon espace de travail à jour."
- " En tant qu'étudiant, je veux recevoir un rappel avant l'échéance d'une tâche, afin de ne pas oublier de rendre mon travail"
- " En tant qu'étudiant, je veux consulter mes échéances dans un calendrier, afin d'anticiper les semaines où ma charge de travail sera importante"
- " En tant qu'étudiant, je veux décomposer un devoir en plusieurs sous-tâches, afin d'avancer progressivement sur les travaux complexes."
